你遇到的问题非常典型，是 **Tortoise-ORM 与 FastAPI 结合使用时常见的陷阱**。

---

## ❌ 错误核心

```python
AttributeError: all
```

在 `student.py` 的这个函数中：

```python
@student_api.get('/')
async def stuinfo():
    all_stu_info = Student.all()  # ❌ 报错！
    return {'all_stu_info': all_stu_info}
```

### ❌ 错误原因

1. **`Student.all()` 是一个 **`await`**。
2. **你没有 `await` 它**，所以返回的是一个 `QuerySet` 对象，而不是数据。
3. **更严重的是**：`QuerySet` 被直接返回给 FastAPI，而 FastAPI 试图把它序列化成 JSON，但它不是可序列化的对象。

---

## ✅ 正确写法（修复）

### ✅ 修复 1：使用 `await` 并 `.values()` 或 `.all().values_list()`

```python
@student_api.get('/')
async def stuinfo():
    # ✅ 正确：await 并转换为字典列表
    all_stu_info = await Student.all().values()  # 返回字典列表
    return {'all_stu_info': all_stu_info}
```

或者：

```python
all_stu_info = await Student.all().prefetch_related('clazz', 'courses')  # 如果想获取外键和多对多数据
return {'all_stu_info': all_stu_info}
```

## 🔍 为什么 `Student.all()` 会报 `AttributeError: all`？

这其实是一个 **误导性错误**！

你看到的 `AttributeError: all` 并不是说 `Student` 没有 `all()` 方法，而是：

> **`pydantic` 在生成 OpenAPI 文档时，试图检查 `Student` 类型，但它把 `models.Student` 当成了 Pydantic 模型，而不是 Tortoise 模型。**

你代码中有这一行：

```python
from models import Student
```

但你在 `api/student.py` 中 **也定义了一个同名的 Pydantic 模型**（虽然注释掉了）：

```python
# class Student(BaseModel):
#     name: str | None = None
#     ...
```

即使注释了，**FastAPI 的依赖注入系统可能仍然混淆了 `models.Student` 和局部的 `Student` 类名**。

---

## ✅ 完整修复建议

### ✅ 1. **避免命名冲突**（强烈建议）

不要在 `api/student.py` 中使用 `Student` 作为变量或类名，建议改名：

```python
from models import Student as StudentModel  # 明确区分

@student_api.get('/')
async def get_all_students():
    students = await StudentModel.all().values(
        'id', 'name', 'sno', 'clazz__name'  # 可以展开外键
    )
    return {'students': students}
```

---

### ✅ 2. **添加 Pydantic 模型用于请求/响应**（推荐）

```python
from pydantic import BaseModel
from typing import Optional

class StudentOut(BaseModel):
    id: int
    name: str
    sno: int
    pwd: str
    clazz_id: int

class StudentIn(BaseModel):
    name: str
    pwd: str
    sno: int
    clazz_id: int
```

然后用于接口：

```python
@student_api.get('/', response_model=list[StudentOut])
async def get_all_students():
    students = await Student.all().values()
    return students
```

## 🚫 为什么 `input()` 不能用？

你在 `mofy_stu` 中用了：

```python
newname = input('输入新的名称')
```

这是 **阻塞式同步函数**，在 FastAPI 异步接口中 **完全不能用**！

HTTP 接口的数据应该从 **请求体** 获取，比如用 Pydantic 模型。

## ✅ 问题汇总 & 修复方案

### ❌ 问题 1：`Student.all().values_list()` 没有 `await`

```python
all_stu_info = Student.all().values_list()
```

- ❌ 错误：这是个异步查询，必须用 `await`
- ❌ 并且 `.values_list()` 返回的是元组，不如 `.values()` 友好（JSON 序列化更清晰）

### ✅ 修复：
```python
all_stu_info = await Student.all().values()  # 加 await，返回字典列表
```

---

### ❌ 问题 2：`Student.get(id)` 没有 `await`

```python
stuinfo_one = Student.get(student_id)
```

- ❌ `get()` 是异步方法，必须 `await`
- ❌ 参数写法错误，应该是 `Student.get(id=student_id)`

### ✅ 修复：
```python
stuinfo_one = await Student.get_or_none(id=student_id)
```

> ⚠️ 强烈建议使用 `get_or_none()`，避免抛出 `DoesNotExist` 异常

---

### ❌ 问题 3：`addstu(stuinfo=Student)` 写法完全错误

```python
async def addstu(stuinfo=Student):
```

- ❌ 这不是 Pydantic 模型，FastAPI 不知道如何解析请求体
- ❌ `Student` 是 Tortoise 模型，不能直接作为参数

### ✅ 修复：定义 Pydantic 模型用于接收数据

```python
from pydantic import BaseModel

class StudentCreate(BaseModel):
    name: str
    pwd: str
    sno: int
    clazz_id: int  # 外键关联 Clazz 的 id
```

然后：

```python
async def addstu(student: StudentCreate):
    new_student = await Student.create(**student.dict())
    return {"id": new_student.id, "msg": "创建成功"}
```

---

### ❌ 问题 4：`input()` 在 Web 接口中完全不可用

```python
newname = input('输入新的名称')
```

- ❌ `input()` 是同步阻塞函数，只能在终端用
- ❌ FastAPI 是异步 Web 框架，无法使用 `input`

### ✅ 修复：从请求体获取新名字（用 Pydantic）

```python
class StudentUpdate(BaseModel):
    name: str | None = None
    pwd: str | None = None
    sno: int | None = None
    clazz_id: int | None = None

@student_api.put('/{student_id}')
async def mofy_stu(student_id: int, data: StudentUpdate):
    stu = await Student.get_or_none(id=student_id)
    if not stu:
        return {"error": "学生不存在"}
    
    # 更新字段
    if data.name is not None:
        stu.name = data.name
    if data.pwd is not None:
        stu.pwd = data.pwd
    if data.sno is not None:
        stu.sno = data.sno
    if data.clazz_id is not None:
        stu.clazz_id = data.clazz_id
    
    await stu.save()
    return {"msg": "更新成功", "data": await stu.values()}
```

---

### ❌ 问题 5：删除接口没有返回状态码

```python
if stu:
    await stu.delete()
```

- ❌ `stu = Student.get(...)` 没有 `await`
- ❌ 没处理“找不到”的情况
- ❌ 删除后没返回明确结果

### ✅ 修复：
```python
@student_api.delete('/{student_id}')
```

## ✅ 修复后的完整 `student.py` 代码

```python
"""
@File    : student.py
@Editor  : 百年
@Date    : 2025/9/18 16:31 
"""

from fastapi import APIRouter
from models import Student
from pydantic import BaseModel
from typing import Optional

student_api = APIRouter()

# ========== Pydantic 模型（用于请求/响应）==========
class StudentCreate(BaseModel):
    name: str
    pwd: str
    sno: int
    clazz_id: int

class StudentUpdate(BaseModel):
    name: Optional[str] = None
    pwd: Optional[str] = None
    sno: Optional[int] = None
    clazz_id: Optional[int] = None


# ========== 查询所有学生 ==========
@student_api.get('/')
async def stuinfo():
    all_stu_info = await Student.all().values(
        'id', 'name', 'sno', 'clazz__name'  # 可展开外键
    )
    return {'all_stu_info': all_stu_info}


# ========== 添加学生 ==========
@student_api.post('/')
async def addstu(student: StudentCreate):
    new_student = await Student.create(
        name=student.name,
        pwd=student.pwd,
        sno=student.sno,
        clazz_id=student.clazz_id
    )
    return {
        'msg': '学生添加成功',
        'student': {
            'id': new_student.id,
            'name': new_student.name,
            'sno': new_student.sno
        }
    }


# ========== 查找单个学生 ==========
@student_api.get('/{student_id}')
async def stuinfo_one(student_id: int):
    stu = await Student.get_or_none(id=student_id)
    if not stu:
        return {'error': '学生不存在'}
    return {'学生信息': await stu.values()}  # 返回字典


# ========== 编辑某个学生 ==========
@student_api.put('/{student_id}')
async def mofy_stu(student_id: int, data: StudentUpdate):
    stu = await Student.get_or_none(id=student_id)
    if not stu:
        return {"error": "学生不存在"}

    if data.name is not None:
        stu.name = data.name
    if data.pwd is not None:
        stu.pwd = data.pwd
    if data.sno is not None:
        stu.sno = data.sno
    if data.clazz_id is not None:
        stu.clazz_id = data.clazz_id

    await stu.save()
    return {"msg": "更新成功", "data": await stu.values()}


# ========== 删除某个学生 ==========
@student_api.delete('/{student_id}')
async def del_stu(student_id: int):
    deleted_count = await Student.filter(id=student_id).delete()
    if deleted_count == 0:
        return {"error": "学生不存在"}
    return {"msg": "删除成功"}
```
