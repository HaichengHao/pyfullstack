# flask之绘制图片生成验证码 
[flask-wtf官方链接](https://flask-wtf.readthedocs.io/en/1.2.x/form/#recaptcha)

## 使用的是recaptcha

### 首先要设置公钥和私钥
> 我们可以通过`app.config['RECAPTCHA_PUBLICKEY']`   
> 以及`app.config['RECAPTCHA_PRIVATEKEY']`来设置    
> 
> 也可以通过在config.py中写好    
> `RECAPTCHA_PUBLICKEY='XXXXX'`   
> `RECAPTHCA_PRIVATEKEY='XXXX'`  
> `RECAPTCHA_PARAMETERS = {'hl':'zh','render':'explicit'}   `  
> `RECAPTCHA_DATA_ATTRS={'theme':'dark'}   `   
> 的方式来设置
>    


### 之后在form中这样设置  
```python
from flask_wtf import FlaskForm,RecaptchaField


class LoginForm(FlaskForm):
 recaptcha = RecaptchaField(label='输入验证码')
```

### 接着在html中这样写   
```html
<p>{{ login_form.recaptcha.label }}:{{ login_form.recaptcha }}</p>
```
